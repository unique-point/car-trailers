# Visual direction

A photographic industrial storefront with a strong charcoal wordmark, yellow-green actions and spacious product presentation. The headquarters banner is a separate, uninterrupted image beneath the main heading so its lettering and central trailer remain readable.

| Token | Value | Use |
|---|---|---|
| Navigation lime | #C3D72E | Quote band and navigation accents |
| Primary accent | #E0E722 | Main actions |
| Hover | #B8BF1D | Action hover |
| Charcoal | #1A1A1A | Headings, wordmark, footer |
| White | #FFFFFF | Main surface |
| Neutral | #F7F7F2 | Alternating panels |
| Body | #374151 | Reading text |

Palette source: https://foxmowing-nsw.com.au/ public styling. Layout, writing and brand treatment are original. System fonts avoid remote font requests. Main body text is 16px; primary controls have visible focus and generous touch areas. Reduced-motion preferences remove transitions. Mobile navigation includes the saved selection and comparison; the wide banner scales without cropping the central subject.

No invented badges, reviews, prices or address appear. Facility and product imagery is marked illustrative. Numeric specification and price filters should be introduced once approved values exist, rather than presented as nonfunctional controls.
